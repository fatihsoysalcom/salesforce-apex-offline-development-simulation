# Salesforce Apex Offline Development Simulation

This Python script simulates a developer working with Apex code when the Salesforce org is inaccessible. It demonstrates how Apex code can be compiled and queued locally for later deployment, bypassing the direct dependency on a live Salesforce connection during an outage.

## Language

`python`

## How to Run

Run this script using Python: `python offline_apex_sim.py`
